# Java OOP Projects

This repository contains a collection of Java projects and exercises focusing on Object-Oriented Programming (OOP) concepts. It serves as a personal archive to track progress and to assist others in understanding different problem-solving approaches.

## 📚 Contents

The repository includes the following projects:

- **Library Management System**
  - A simple system to manage library operations such as adding, removing, and searching for books.

- **Odev**
  - Contains various assignments and exercises related to OOP concepts.

- **Timer**
  - A project demonstrating time-related functionalities, possibly including countdowns or stopwatches.

## 📁 Directory Structure

Each project is organized into its own directory:

- `Library Managment System/`
  - Contains the source code for the Library Management System project.

- `odev/`
  - Includes various assignment files and exercises.

- `timer/`
  - Contains the Timer project files.
